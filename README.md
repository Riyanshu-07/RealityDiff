# RealityDiff

### AI-Powered Image Reality & Manipulation Analysis

RealityDiff is an AI-powered image analysis project designed to analyze images and identify visual inconsistencies or signs of manipulation. The project explores computer vision and machine learning techniques to help distinguish between authentic and potentially manipulated visual content.

---

## Overview

With the increasing use of AI-generated and digitally manipulated images, identifying whether visual content is authentic has become increasingly important.

**RealityDiff** aims to provide an intelligent analysis pipeline that examines an input image and produces insights related to its visual authenticity.

The project focuses on applying AI/ML and computer vision techniques to image analysis in a practical, user-friendly application.

---

## Features

- 🖼️ Image upload and analysis

Installation
1. Clone the Repository
git clone https://github.com/Riyanshu-07/RealityDiff.git
2. Navigate to the Project
cd RealityDiff
3. Create a Virtual Environment
python -m venv venv
Activate it:
macOS / Linux
source venv/bin/activate
Windows
venv\Scripts\activate
4. Install Dependencies
pip install -r requirements.txt
Run the Application
If the application entry point is app.py:
streamlit run app.py
The application will open in your browser.
